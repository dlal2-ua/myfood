# MyFood — Sistema de diseño

Pendiente de desarrollo visual completo (Fase 2 en adelante). Fundamentos ya fijados:

- **Tipografía:** Inter (variable).
- **Paleta:** verde principal `#16A34A`, fondo claro `#FAFAF9`, texto `#1C1917`. Modo oscuro obligatorio desde el principio.
- **Semánticos de macro (fijos en toda la app):** proteína `#EF4444`, grasa `#F59E0B`, carbohidratos `#3B82F6`, agua `#0EA5E9`.
- **Gamificación ética (R10):** nunca colorear en rojo por superar el objetivo calórico; el anillo de progreso usa siempre el verde principal de forma neutra.
